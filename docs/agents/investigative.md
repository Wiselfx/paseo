# investigative.md

Pre-scope checklist. Green checks precede code.

## Assumptions

Each: verified-in-code (file:line), unverified, folklore.
Unverified items are checks, not plans.

## Bias

Preferred path and alternative, one line each. The flipping
fact. "Small" means counted files and lines, both named.

## Precedent

Closest existing mechanism wins. Then confirm the trigger
reaches the hook. Trace caller to callee.

## Ripples

All callers of each touched function. Platform branches state
the other platform. Lost capabilities name their remaining path.

## Second pass

Narrow questions, line cap, file:line evidence. The two
load-bearing claims get re-checked by hand.

## Output

Corrected file list. Open verifications. Both go in `docs.md`.

## Known traps

- Bare URLs never become fence blocks (linkify path). A
  fence-only patch fires on nothing.
- Touch coordinates live on `changedTouches[0]`, not the event.
  Null point means the menu never opens. Anchor to the row.
- `user-select:none` ends text selection. Copy survives via menu.
