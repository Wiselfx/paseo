# Anthropic faces

`AnthropicSansWebText.ttf`, `AnthropicSerifWebText.ttf`, and `AnthropicMonoWeb.ttf`
are Anthropic's Claude interface faces. They are not publicly distributed; these
copies come from the DSH Claude Style plugin
(`refs/dsh-claude-style/packages/assets/src/fonts/anthropic`, MIT-licensed
repository, fonts themselves Anthropic's). They are used here as a local
experiment in matching Claude's typography, at the experiment owner's request —
not redistributed as part of any Paseo release.

Loaded by `src/styles/fonts.ts`; named by the stacks in `src/styles/theme.ts`.
